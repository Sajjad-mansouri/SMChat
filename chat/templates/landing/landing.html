Everything you need to stay connected

SMChat includes account management, real‑time messaging, group roles, and a clean API — all in one place.

Accounts & profiles

Email‑based sign‑up, activation, password reset, profile images, and account deletion. Full JWT support.

Direct, groups & channels

Private one‑on‑one chats, public or private groups with role‑based memberships, and broadcast‑style channels.

WebSocket messaging

Instant message delivery over Django Channels. Replies, file and image attachments, read tracking, and upload progress.

Membership & blocking

Owner / admin / member roles, join requests, block‑list enforcement, and object‑level permissions.

User & group search

Search users by username, and find public groups and channels by name. Excludes yourself from results.

REST API + JWT

Django REST Framework endpoints, token obtain/refresh, and custom JWT middleware for WebSocket authentication.
